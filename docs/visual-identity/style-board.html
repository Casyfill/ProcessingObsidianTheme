Notes

    
    
      
  • Accent. #0564FF is today's processing.org and logo blue, which makes it the most recognisable choice but the closest to a copy. The PDE 4 editor blue #0088F6 is just as bright and comes from the tool itself. Every option has a "text" sibling that passes AA (4.5:1) for links, plus a variant for dark mode.
    • 
      
  • Fonts. All five are SIL OFL 1.1, so bundling them is allowed. Adobe reserves the name "Source": a subset of Source Sans or Source Code Pro must be renamed, as Processing did with "Processing Sans". The website fonts (Space Grotesk, JetBrains Mono, Vollkorn) can be subset freely.
    • 
      
  • Run circle. Obsidian's equivalent of the PDE's Run button is the Reading/Editing toggle in the note header. With "Reading toggle as ▶" selected, the toggle becomes a filled accent circle with a play glyph. A theme can swap the icon with a CSS mask, at the cost of a slightly fragile selector.
    • 
      
  • Code. The Minerals colours come straight from processing4/build/shared/lib/theme/Minerals. The ten light Minerals share Kyanite's syntax and only change the chrome; the six dark ones (antimony, bauxite, fluorite, garnet, malachite, pyrite) each have their own. They were made for pure white and black backgrounds, so on ours the colours that failed AA were nudged until they passed. Kyanite's teal keyword, for example, goes from #30987F to #277D68.
    • 
      
  • Icons. A theme can restyle every icon at once: stroke weight (--icon-stroke), caps and corners, size and colour. It can also swap individual icons, by hiding Obsidian's SVG and drawing a CSS mask in its place. That second route is fragile: most buttons can only be targeted by their aria-label, which is translated into the user's language and changes between Obsidian versions. So a few swaps are realistic (Run ▶ for reading view, for example), but a full custom icon set isn't. Users who want that can install the Iconize plugin.
    • 
      
  • Mono headings. Obsidian has variables for this (--h1-font to --h6-font and --inline-title-font), so it's cheap and robust. Mono section headings keep the IDE feel without a heavy title. My recommendation is to try that one first.
